# آوند (AVAND) — مرکز فایل خصوصی روی شبکه‌ی محلی
این نرم‌افزار از مجموعه «انجام وظیفه» است؛ به جهت از بین بردن رانت آپلودسنترهای ایرانی ;)
حمایت از پروژه‌ها: **https://daramet.com/zohalgame**

## نصب (ویندوز ۱۰/۱۱)
1. فایل `Avand-Setup-1.0.0.exe` را اجرا کنید (نیازی به دسترسی مدیر نیست). صفحه‌ی نصب در مرورگر باز می‌شود.
2. مسیر نصب و **پوشه‌ی نگهداری فایل‌ها** (مثلاً روی درایو D) را انتخاب کنید و «نصب آوند» را بزنید.
3. آوند اجرا می‌شود و صفحه‌ی ورود باز می‌شود. اولین حساب (مدیر) را بسازید. برای بقیه از «پنل مدیریت ← کدهای دعوت» کد بسازید.
4. از موبایل/لپ‌تاپ‌های همان شبکه: `http://avand.local` (یا آدرس IP که در «تنظیمات» برنامه نوشته شده). روی بعضی اندرویدها `.local` کار نمی‌کند؛ آدرس IP را بزنید.

در اولین اجرا ویندوز درباره‌ی فایروال می‌پرسد؛ «شبکه‌ی خصوصی» را تأیید کنید (یا هنگام نصب گزینه‌ی فایروال را بزنید).
اگر SmartScreen هشدار داد: «More info ← Run anyway» (برنامه امضای دیجیتال خریداری‌شده ندارد).

## بستن / حذف
- بستن: تنظیمات ← «بستن برنامه‌ی آوند» (فقط مدیر، فقط از همان رایانه).
- حذف: Settings ویندوز ← Apps ← Avand. **پوشه‌ی فایل‌ها هرگز حذف نمی‌شود.**

## امنیت
فقط IPهای شبکه‌ی خصوصی/لوکال پذیرفته می‌شوند؛ کوکی SameSite=Strict؛ محدودیت تلاش ورود؛ فایل هر کاربر حتی از مدیر هم جداست؛ رمزها با PBKDF2 ذخیره می‌شوند.
ذخیره‌ی رمز در مرورگر پشتیبانی می‌شود (فرم‌های استاندارد).

## شبکه‌ی مرکزی آوند (کپچا + به‌روزرسانی)
پنل مدیریت ← «شبکه‌ی مرکزی»: روشن = دروازه‌ی کپچا (VoidCaptcha) + به‌روزرسانی خودکار از گیت‌هاب. خاموش = حالت کاملاً لوکال، بدون کپچا و **بدون به‌روزرسانی** (قطع دسترسی از شبکه‌ی مرکزی).

## انتشار نسخه‌ی جدید با به‌روزرسانی خودکار (مخزن: voidlessorg/avand)
1. `avand-tools.exe keygen` ← کلید عمومی و خصوصی (خصوصی را مخفی نگه دارید).
2. بیلد: `go build -ldflags "-s -w -H windowsgui -X main.Version=1.0.1 -X main.UpdateRepo=OWNER/REPO -X main.UpdatePubKey=<PUBLIC>" -o avand.exe .`
3. `avand-tools.exe sign avand.exe v1.0.1 <PRIVATE>` ← فایل `avand.exe.sig`
4. (نسخه‌ی ۱.۰.۰ از قبل امضا شده: `dist/avand.exe` و `dist/avand.exe.sig`.) در GitHub یک Release با تگ `v1.0.1` بسازید و `avand.exe` و `avand.exe.sig` را پیوست کنید. نسخه‌ی نصب‌شده امضا را بررسی و خودش را عوض می‌کند.
(برای نصاب جدید: آیکون در `icon_windows_amd64.syso`، نصاب در پوشه‌ی `installer/` با `avand.exe` کنار آن.)

## فونت
فونت وزیرمتن (Regular/Bold/Black) و فونت دست‌نویس «دست‌نویس» داخل برنامه جاسازی شده‌اند؛ نیازی به اینترنت یا نصب جداگانه نیست.
